Proposals

members only, for now

ORG decides together: each proposal goes to a vote of the members, and the outcome is written into its decisions log. The proposals themselves are private to ORG's members; there is no public preview of them yet. What ORG has decided shows up in its plain-language record, the ORG AstroLog.

How to ask for the members' room

Behind this shelf is ORG's private reading room, where members read drafts before they are public: github.com/Octagon-Religious-Research-Group-ORG/reading-room. It opens with a free GitHub account that ORG has invited; until then the link shows GitHub's "page not found", which only means "not invited yet" or "signed out".

  1. Make a free account at github.com and turn on two-factor authentication.
  2. Ask to join, using one of the addresses ORG publishes on its contacts page: org@orgspirituality.org, or ORG (Public) on Telegram. Say which GitHub account is yours.
  3. When an officer says yes, you get an invitation from GitHub by email. Accept it, and the reading room opens in your browser.

Becoming a member of ORG is a separate step, described on orgspirituality.org/join. Never send a password or a code to anyone who asks for one; nobody at ORG ever needs it.
